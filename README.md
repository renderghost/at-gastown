# AT Gastown

A prototype of a gather.town-style space for atproto events. A **town** belongs to an event, holds **places** (Office, Park, Jungle, Conference hall, City square), and places hold **zones** with audio rules (1:1, 1:many, many:many, one at a time, focus).

Every pixel of the map is generated by code from a small town record. Nothing on the map is an image file. The people on the map are everyone who RSVP'd to the linked event, drawn with their [rpg.actor](https://rpg.actor) sprites.

The sidebar has two tabs:

- **Attend** (default): the event, live streams, places and a searchable list of attendees, each with "walk to".
- **Organise**: town settings, drawing and editing places and zones, checks, the town record and a reset button.

**Streamplace:** a zone can show a live [Streamplace](https://stream.place) stream on an in-world screen. The demo's keynote stage shows `pubtoons.com`. Sound only plays inside the same place, full within 4 tiles of the screen and fading out by 13. Walk close for a preview card, or click the screen to watch in a theatre view with full screen.

**Demo:** the town for [AtmosphereConf 2027](https://pdsls.dev/at://did:plc:3xewinw4wtimo2lqfy5fm5sw/community.lexicon.calendar.event/3mw74r4r3gsej).

## What's here

| Path | What it is |
| --- | --- |
| `index.html` | The built, self-contained page served by GitHub Pages |
| `src/town.template.html` | The page source, with a `/*__DATA__*/` slot for the event snapshot |
| `data/sprites.json` | Snapshot of the event, its RSVPs and their rpg.actor sprite sheets |
| `data/nosprite.json` | RSVPs without an rpg.actor sprite (handle, going or interested) |
| `scripts/build.py` | Injects the snapshot into the template to produce `index.html` |

Rebuild after editing the template:

```sh
python3 scripts/build.py
```

## Notes

- The RSVPs and sprites are a snapshot taken on 15 November 2026. On a normal web host the page can read them live from the network, which is the obvious next step.
- The town record uses a placeholder NSID (`com.example.pixelspace.town`) and links to the event with a strong ref (URI and CID).
- The map art uses 16px tiles at 2×, while rpg.actor sprites are native 48px frames, so sprite pixels are half the size of map pixels.
